## Slug font rendering

Text is drawn directly from glyph outlines using the Slug algorithm by Eric Lengyel, as implemented in handrail (`handrail/code/handrail/media/font.h` and `handrail/code/shaders/font_vector.glsl`).

- Paper: Eric Lengyel, "GPU-Centered Font Rendering Directly from Glyph Outlines", *Journal of Computer Graphics Techniques* (JCGT), vol. 6, no. 2, 2017.
- Reference code: https://github.com/EricLengyel/Slug

Per that repository, the Slug patent has been dedicated to the public domain, and software distributed using the code must give credit.
